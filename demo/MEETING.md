# Meeting transcription and speaker analysis

Meeting mode is optional. It requires a compatible Audio8 ASR Infinite
release in `components/asr` and its matching transcription models. The
meeting integration is pending that release. The default Web Demo handles
speaker diarization with the [main installation and model download](../README.md).

The meeting view pairs live transcription with speaker analysis. After
pausing or finishing transcription, choose **Analyze speakers** to associate
the transcript with the offline speaker timeline.
